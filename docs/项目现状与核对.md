## 一、项目概览

**锐智工厂 · 工业互联网实训闯关游戏**（局域网教学用，IIoT 课程）。

| 项 | 现状 |
|---|---|
| 后端 | Node.js + Express 4 + sql.js（SQLite wasm），密码用 bcryptjs，安全中间件 helmet + express-rate-limit |
| 前端 | 原生 HTML/CSS/JS，**ES Module 模块化**（无构建步骤、零打包），ZzFX/ZzFXM 程序化音效+音乐 |

| 运行 | `npm start` / `npm run dev`（node --watch），监听 `0.0.0.0:3000`（`PORT` 可改） |
| 数据库 | 真实文件 `data/game.db`（非内存），写操作原子落盘（tmp + rename） |
| Git | `main` 分支，约定式提交（feat/fix/docs/refactor/chore），远程 origin/main |

依赖（package.json）：`express`、`sql.js`、`bcryptjs`、`csurf`（未用，保留）、`express-rate-limit`、`helmet`。

## 三、页面与流程

```
index.html（登录）
 ├─ 学生：POST /api/login → 登录成就弹窗 → （mustChangePassword ? 强制改密弹窗 : 直接进入）
 │        → map_proto.html（厂区地图）→ 点建筑 → room.html?room=<区域名>
 │              └ room-task-host.js 在房间内打开任务模态（真实任务，完成/关闭回房间）
 ├─ 教师：POST /api/login（name=teacher）→ 强制改密 or → teacher.html（列表/详情 student_detail.html）
旧入口：student.html（跳转壳）
 ├─ 无参数 → location.replace('map_proto.html')
 ├─ ?level=X（无 task）→ room.html?room=X
 └─ ?task=xx / ?open=xx → 停留在壳内，js/app.js 加载后弹任务模态/功能浮层（app.js 亦为 ?open 功能页宿主）
```

- map_proto.html、room.html、teacher.html、student_detail.html、index.html 均为**内联脚本页面**，不走 js/app.js（room.html 额外挂 `js/room-task-host.js`）。
- 小游戏/图鉴/排行榜/钱包等浮层只存在于 js/app.js 的宿主页（student.html 任务模式 / map 跳转场景）。
- 学生登录成功后跳 **map_proto.html**（不是 student.html）。

## 五、数据库（db.js）

表：`students` / `teacher`（单行 id=1）/ `sessions` / `bug_reports` / `login_audit`。

- students 列：name、password（bcrypt，兼容旧 SHA256/明文）、check_data、stars_data、achievements、level_finish_times、teacher_awards、last_login_date、login_streak、login_count、coins、inventory、last_salary_date、month_salary_total、login_ach_notified、password_changed_at、must_change_password
- init 自动建表 + **迁移**：旧库缺列自动 `ALTER TABLE ADD COLUMN`（不改 schema 也能升级）
- 教师账号：init 时若不存在则创建（bcrypt(admin123)，must_change_password=1 → **首次登录强制改密**）

- 写操作统一 `save()`：tmp 文件 + rename 原子替换；`updateSessionActivity`/`cleanupExpiredSessions`（1 分钟节流）不每次写盘
- 工资档位 SALARY_TABLE：0→100 / 1000→200 / 2500→350 / 4500→500 / 7000→800 金币/日（跨月重置月累计）
- 导出但**未被路由调用**：`recordLogin`（连续登录/last_login_date）、`markLoginAchNotified`（见第十节问题 2/4）

## 六、前端模块

### 入口与挂载（重要约束）
- `js/app.js` 是唯一宿主 module：import 全部 core/ui/interactions/games，末尾 **`Object.assign(window, …)` 挂函数常量 + `Object.defineProperty(window, …)` getter 挂可变状态**（content/gameState/streak/errors 等）。
- 子模块（core/ui/interactions/games）**只 import core/* 与兄弟模块；其余公共函数/状态一律经 `window.*`**（避免循环依赖）。新增函数若被 onclick/子模块引用，必须挂 window；可变状态挂载需带 setter。
- `interactions/*.js` 通过 import 副作用触发 `registerInteraction`（app.js 里 import 即注册）。
- 详见 `docs/架构设计.md`（权威）。

### 任务类型（interactions/，16 个注册）
terminal、quiz、chain_quiz、fill_blank、progress_bar、**install_wizard**（44 任务，主力）、scenario_match、sort、code_review、ethics、diagnosis_tree、drag_classify、boss_fight、**config_debug**、**log_forensics**、default（兜底）。
→ 新增任务类型 = 新建 `interactions/xxx.js` + `registerInteraction('xxx', { render, … })` + 在 app.js 和 room-task-host.js 两处 import（房间内任务也用它）。

### 小游戏（games/，26 款 + stacked 番外）
typing、shooter、racing、flappy、mole、pacman、tank、breakout、sorter、forge、ll、pipe、m3、td、maze、hack、tyc、lzr、boss、memory、match、quick、storm、alarm、t48、snake（stacked 未列入 smoke 与专区）。
- 约定：`openXxx(cfg, onComplete)`；**关闭必须对称清理监听 + cancel rAF/interval**（防泄漏，smoke 覆盖）。
- 游戏定义在 `game-content.json` 各关 tasks 的 config 里（blockTasks/type/size 等），`ui/gamezone.js` 渲染专区与解锁（完成所在关 80%~100% 任务解锁）。

### UI 模块（ui/）
main（渲染工厂/任务/结算）、gamezone（专区/游戏房）、wallet（工资商城/皮肤）、leaderboard（排行/战绩）、achievements（成就评估/弹窗队列）、pedia（术语图鉴，localStorage）、password、modals（升级/欢迎/关卡结算）、tutorial（首次引导）、header。

### 核心（core/）
api（fetch 封装 5s 超时、401 清 session 跳登录）、state（XP/等级/进度计算）、fx（打字机/厂长气泡/特效）、sound（ZzFXM 音乐按区域）、utils、kbd（键盘导航）、cmd-annotate（命令中文注释）。

## 十、核对发现的问题清单（修正/开发优先参考）

1. **`GET /api/student/me` 缺前端依赖字段**（routes/student.js:206-228 与 core/api.js:39-55 不一致）：

## 十一、开发与运维注意事项

- **进程红线**：重启服务用 `kill $(lsof -t -i:3000)`；**严禁** `pkill -f "node.*server.js"` 等泛化模式（会误杀本机 codex-router 网关 8787，导致当前会话断流）。
- **推代码**：GitHub 直连不稳，用 `/home/lee/bin/git-push-bg.sh [仓库] [远程] [分支]`（后台重试推送，日志 /tmp/git-push-bg-*.log）。
- **改 `game-content.json` 免重启**（mtime 缓存），但改前端 js/css 后需浏览器强制刷新（静态文件已 no-cache，一般刷新即可）。
- **server.js 的 helmet CSP 必须保留 `scriptSrcAttr: ['unsafe-inline']`**（项目到处是内联 onclick，去掉会导致按钮无反应）；HSTS 已禁用（HTTP 局域网环境）。
- **数据库写操作一律走 db.js 封装**（自动 save），勿手写裸 SQL；批量写用 `db.transaction`（注意：当前封装无 transaction 导出，批量场景直接复用现有函数即可）。
- 新增任务类型记得在 **app.js 与 room-task-host.js 两处** import（否则房间内该类型渲染成 default）。
- 小游戏必须遵循"开/关对称清理"生命周期（rAF/setInterval/监听），否则 smoke/泄漏检查不过。
- 前端模块间通信约定：**import core/*，其余经 window.***（见 docs/架构设计.md），新拆模块照此办理。
- 文档层级：`docs/架构设计.md`（模块现状权威）> `docs/游戏重构规划.md`（小游戏评级/规划）> 本文件（接口与核对）。`设计文档.md` 仅作历史参考。
