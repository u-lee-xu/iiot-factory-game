# 小游戏重构规划（施工图）

> 状态：**四批重构已完成**（待移动端回归）
> 范围：26 款小游戏（8 幕），全部在 `public/student.html` 单文件内
> 原则：**知识=玩法** 优先；先 A 级精修、后 B 级打磨、C 级评估；移动端为硬指标；特效=反馈

---

## 一、评估框架（4 维，满分 5）

| 维度 | 核心问题 | 关键看什么 |
|------|---------|-----------|
| **知识嵌入** | 机制是否"逼"玩家用知识？ | 是否 选对=过关、配对=掌握、克制=理解，还是只贴标签 |
| **上头度** | 有没有连续爽感？ | 成长反馈、压力曲线、连锁/连击、暴击 |
| **移动端** | 竖屏+滑动是否可玩？ | 画布自适应、滑动跟手、触摸命中 |
| **特效画面** | 操作有无反馈？ | 粒子/光晕/飘字/音效/连击动画 |

**验收通用标准（所有游戏）**
- 打开无 JS 报错、关闭无循环泄漏（rAF/setInterval 清理）
- 竖屏 390×844 画布铺满、内容不被裁切
- 有教学引导（首次 `showGameTutorial`）
- 操作有可见反馈（特效/音效/飘字至少其一）

## 三、分批执行路线

### 第一批（A 级精修）：翻牌 + 连连看
- **翻牌**：配对成功连击特效（combo 环+飘字）、翻牌/配对/完成音效、全对完成动画
- **连连看**：加滑动操作、连线消除光效、消除粒子
- **验收**：手机竖屏可玩、0 报错、操作有反馈

### 第二批（A 级精修）：术语防御战 + 数据蜂群
- **术语防御战**：打爆粒子、Boss 特效、同词规避收尾
- **数据蜂群**：子弹光效、命中火花、升级特效

### 第三批（B 级打磨）：sorter / forge / maze / hack / pipe / lzr / tyc / storm / alarm
- 统一加：滑动操作 + 操作反馈特效 + 目标明确

### 第四批（C 级评估）：flappy / tank / breakout / m3 / alarm
- 评估重构 or 替换为更贴知识的游戏（协议分层 / 流量分诊等）
