# 第1章 互联网基础 — 思维导图 ## 〇 课前准备：安装虚拟机环境 - VMware Workstation Pro - Ubuntu Server 22.04 LTS - 网络适配器 → 桥接模式 ## 1.1 从一封邮件到万物互联——互联网的前世今生与TCP/IP ### 互联网发展简史 - 全球互联网五十年 - 萌芽期（1960s-1980s） - ARPANET（1969年，4节点：UCLA/Stanford/UCSB/Utah） - 包交换 vs 电路交换 - 首次通信只传了"LO"两个字母 - 标准化期（1980s-1990s） - TCP/IP协议标准化 - DNS域名系统诞生 - 商业化期（1990s-2000s） - World Wide Web（WWW） - 浏览器大战 - 移动化期（2000s-2010s） - 智能手机普及 - 3G/4G移动互联网 - 万物互联期（2010s至今） - 5G + IoT - 工业互联网 - 中国互联网：从接入者到引领者 - 1994年：全功能接入互联网 - 2024年：网民10.92亿，普及率77.5% - 5G基站425万个，占全球60%以上 - 光纤入户覆盖率超95% - 移动支付年交易规模超500万亿元 ### TCP/IP协议栈：为什么需要分层 - OSI七层模型（了解即可） - TCP/IP四层模型 - 网络接口层（用什么信号传） - MAC地址（全球唯一，类比身份证号） - ARP协议（IP→MAC） - 传输介质（双绞线/光纤/无线电） - 网络层（走哪条路） - IP协议（全网寻址与路由） - ICMP协议（ping原理） - 路由器逐跳转发 - 互联网三层网络架构 - 接入网（最后一公里） - 城域网（城市汇聚） - 骨干网（跨省跨国高速光纤） - ISP分层（第一层骨干层/第二层区域层/第三层本地层） - 传输层（怎么可靠送到） - TCP（三次握手，可靠传输，类比挂号信） - UDP（无连接不可靠，类比明信片） - 端口号 - 应用层（数据是什么） - HTTP/HTTPS - DNS - SMTP/POP3/IMAP - FTP - DHCP - SSH - 数据封装：俄罗斯套娃（层层加头部，到达后层层拆封） ## 1.2 让两台电脑"说上话"——IP配置与连通诊断 ### 实践任务 - 查看本机网络配置 - Windows：ipconfig - Ubuntu：ip addr - 网络连通性诊断四步 - ping 127.0.0.1（回环地址，永远代表本机） - ping 网关（默认网关，通向外部网络的出口） - ping 外网（如8.8.8.8） - tracert/traceroute（追踪数据包路径，TTL控制跳数） - 修改IP地址 - DHCP自动获取 - 静态IP手动设置 ## 1.3 网址背后的秘密——IP地址、域名与网络安全 ### IP地址：互联网的"门牌号" - IPv4：32位，约43亿个地址，A/B/C/D/E类分类 - IPv6：128位，可给地球每粒沙子分配地址 - 公网IP vs 私有IP - 三个私有地址段：10.x / 172.16-31.x / 192.168.x - NAT技术（网络地址转换，类比小区快递柜） - 子网掩码（界定"同网段"范围，类比"同一个小区"） - 默认网关（通向外部网络的出口，类比"小区大门"） ### DNS：互联网的"电话簿" - 域名层级结构 - 根域 → 顶级域 → 二级域 → 主机名 - 解析流程 - 本地缓存 → 运营商DNS → 根服务器逐级查询 - CDN与负载均衡 - DNS劫持（hosts文件被篡改导致域名指向错误IP） ### 常用互联网应用服务与协议 - 客户端-服务器模型（类比餐厅：顾客点菜→厨房做菜→服务员上菜） - DHCP协议：自动分配IP/掩码/网关/DNS ### 互联网安全基础 - CIA三元组 - 保密性（加密） - 完整性（数字签名） - 可用性（防火墙/冗余） - 安全威胁 - 钓鱼攻击、恶意软件、中间人攻击 - 震网病毒（Stuxnet） - 防火墙 - 入站规则（管"外面能不能进来"） - 出站规则（管"里面能不能出去"） - 类比：小区门禁和出门条 - 工业防火墙 vs 家用防火墙 - 工业网络故障排查决策树 - 物理层 → 链路层 → 网络层 → 传输层 → 应用层 - 法律法规 - 《网络安全法》（2017） - 《数据安全法》（2021） ## 1.4 追踪网址的旅程——DNS查询与防火墙配置 ### 实践任务 - DNS查询 - nslookup查询域名 - 换DNS服务器（114.114.114.114） - 反向查询 - 查看/清空DNS缓存 - 防火墙入站规则 - 阻止8080端口（netsh/图形界面） - 防火墙出站规则 - 阻止ping.exe出站 - Ubuntu防火墙对照体验 - ufw deny/delete/status（选做） ## 🎯 课程思政 - 从跟跑到领跑——中国互联网30年 - 网络安全法治意识
