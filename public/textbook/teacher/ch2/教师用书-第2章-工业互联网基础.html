第2章 工业互联网基础（教师用书） ​

本章概述 ​

本章是全书承上启下的关键章节。上一章学生掌握了互联网基础，这一章从消费互联网转向工业互联网，建立工业互联网的概念体系和基本工具使用能力。

本章定位 ​

  • 知识层面：建立工业互联网的完整概念体系（起源、定义、架构、要素）
  • 技能层面：掌握Linux环境下SSH远程管理和基本命令，体验云服务器
  • 素养层面：建立数据闭环思维，理解制造强国战略，树立网络安全法治意识

学情分析 ​

  • 优势：学生有互联网使用经验，容易理解消费互联网的概念
  • 难点：工业场景陌生，对架构的理解容易流于表面
  • 教学策略：用大量真实案例（黑灯工厂、三一挖掘机、劳斯莱斯）替代抽象概念

教学目标 ​

知识目标 ​

  1. 理解工业互联网的定义、起源（德国工业4.0、美国工业互联网、中国制造2025）
  2. 掌握IIRA四层参考架构（边缘层、平台层、应用层、业务层）
  3. 了解工业互联网五大构成要素和产业生态中的四类角色
  4. 理解"数据闭环"在工业互联网中的核心作用

技能目标 ​

  1. 能够在Ubuntu上安装和启动SSH服务
  2. 能够从Windows通过SSH远程登录Linux服务器
  3. 掌握9个Linux基本命令（pwd、ls、cd、mkdir、touch、nano、cat、tree、rm）
  4. 能够在云平台创建ECS实例、配置安全组、远程登录

素养目标 ​

  1. 分层思维：理解复杂系统通过分层实现解耦和复用
  2. 数据闭环思维：建立"感知-传输-分析-决策-执行-反馈"的完整闭环意识
  3. 法治意识：遵守网络安全法律法规，树立工业安全意识
  4. 岗位意识：了解工业互联网工程技术人员的职业标准和能力要求

课时分配与教学安排 ​

课次课时内容教学类型重点/难点教学建议
第1次2h2.1 从黑灯工厂看工业互联网本质（起源+定义+与消费互联网对比）理论重点：三国工业互联网战略对比
难点：工业互联网与消费互联网的本质区别		用大量案例、视频让学生直观感受黑灯工厂
第2次2h2.2 实践：SSH远程管理与Linux命令入门理实混合重点：SSH远程登录
难点：Linux文件系统和命令理解		边讲边练，确保每个学生都能成功登录
第3次2h2.3 IIRA四层架构与工业互联网构成要素理论重点：数据在四层之间的流动
难点：数字孪生概念理解		用预测性维护、大规模定制两个场景贯穿
第4次2h2.4 实践：云服务器注册与远程登录实践重点：云服务器创建与安全组配置
难点：理解云服务器的本质		鼓励学生用学生认证领取免费额度

各节教学实施建议 ​

2.1 从黑灯工厂看工业互联网本质 ​

教学导入（10分钟） ​

互动提问：

  • "你见过自动化程度最高的工厂是什么样的？"
  • "工厂里的网络和我们家里的WiFi有什么不一样吗？"

播放视频：小米亦庄智能工厂/特斯拉上海超级工厂视频（5分钟）

黑灯工厂案例（15分钟） ​

  • 详细讲解三个案例：小米智能工厂、特斯拉焊装车间、三一18号厂房
  • 关键提问："这些工厂关灯后怎么生产？"引出"数据"的核心作用
  • 用空调的闭环控制类比工业互联网的闭环

工业互联网起源（20分钟） ​

国家战略时间侧重点代表案例
德国工业4.02011生产柔性、智能制造西门子安贝格工厂
美国工业互联网2012预测性维护、资产效能GE航空发动机
中国中国制造20252015/2017两化融合、产业升级三一重工

思政融入：

  • 从"中国制造"到"中国智造"的跨越
  • 中国从跟跑到并跑再到领跑的机遇

四项关键技术成熟（15分钟） ​

  • 传感技术：从昂贵到便宜
  • 通信技术：从有线到5G、TSN
  • 云计算：从自建机房到弹性扩容
  • AI与机器学习：从专家经验到自动学习

定义与对比（20分钟） ​

  1. 给出三个机构的定义（IIC、AII、学术界）
  2. 关键对比表讲解：消费互联网 vs 工业互联网
  3. 两个震撼场景：
    • 刷抖音卡顿vs机械臂撞坏工件（延迟后果对比）
    • 家用路由器vs工业路由器（工作环境对比）

回顾反思（10分钟） ​

  • 小组讨论3分钟，然后请2-3组分享
  • 问题："你宿舍的路由器是工业互联网吗？"

2.2 动手实践：SSH远程管理与Linux命令入门 ​

实践准备 ​

课前检查：

  • 确保机房电脑可以安装VMware
  • 提前克隆好Ubuntu虚拟机镜像，避免课上安装浪费时间
  • 确保网络环境支持桥接模式（可选：提前准备好网络故障模拟场景）

教学流程 ​

环节1：SSH服务安装与启动（20分钟）

  1. 在VMware窗口直接登录Ubuntu
  2. 演示apt update、apt install openssh-server
  3. 演示systemctl status ssh查看状态
  4. 演示ip addr查看IP地址
  5. 学生练习：每人完成这四个步骤，记录下自己的虚拟机IP

环节2：从Windows SSH登录（25分钟）

  1. 讲解SSH是什么（远程管理协议）
  2. 演示Windows终端执行ssh student@xxx.xxx.xxx.xxx
  3. 讲解host key确认、密码输入（不显示字符是安全设计）
  4. 学生练习：相互ping对方的虚拟机，相互SSH登录（如果环境允许）

环节3：Linux基本命令（40分钟） 建议教学节奏：

  • pwd、ls、ls -l、ls -a（10分钟，边讲边练）
  • cd /home、cd ~、cd ..（10分钟）
  • mkdir、touch、echo、cat、nano（15分钟，nano重点讲解）
  • tree、cp、mv、rm（5分钟，强调rm不可恢复）

关键点提醒：

  • Linux路径分隔符是/不是\
  • 区分大小写
  • rm删除不可恢复（提醒学生谨慎操作）

环节4：软件包管理apt（15分钟）

  1. 讲解apt是"应用商店"
  2. 演示apt install curl
  3. 演示curl ifconfig.me、curl wttr.in（趣味演示，提高兴趣）
  4. 学生练习：安装curl并试用

常见问题与解答 ​

学生问题解答要点
SSH连接被拒绝检查SSH服务是否启动（systemctl status ssh），检查IP地址是否正确
桥接模式无法获取IP尝试NAT模式（但同学之间无法互访），或检查网络限制
rm删错了文件怎么办抱歉，Linux下rm删除不可恢复，操作前请三思
nano编辑器怎么用^X是Ctrl+X，然后Y保存，回车确认文件名

评价设计 ​

  • 过程性评价：检查每个学生成功完成SSH登录
  • 实践任务评价表：学生自评+互评+师评

2.3 IIRA四层参考架构与工业互联网构成要素 ​

教学导入（5分钟） ​

提问回顾："上一章讲的TCP/IP是四层，这一章的IIRA也是四层，它们有什么关系吗？" 回答引导：TCP/IP解决网络通信，IIRA解决工业系统架构

IIRA四层参考架构（30分钟） ​

层级功能类比对应工业元素
边缘层数据采集、指令执行眼睛、手脚传感器、PLC、机器人
平台层数据存储、分析、AI大脑云平台、大数据引擎
应用层呈现给人使用界面MES、预测性维护APP
业务层经营决策大脑皮层ERP、供应链管理

讲解策略：

  • 每个层级用一句话、一个类比、一个工业元素讲清楚
  • 建筑蓝图类比贯穿始终

数据流动（30分钟） ​

两个核心场景详细讲解：

场景1：预测性维护

  • 边缘层：振动传感器采样
  • 平台层：AI模型分析振动特征
  • 应用层：手机APP弹出预警
  • 业务层：计入OEE报表

场景2：大规模定制

  • 业务层：用户在线下单
  • 平台层：订单管理、排产引擎
  • 应用层：工位显示屏显示参数
  • 边缘层：裁床、缝纫机执行

可视化建议：

  • 在黑板上画数据流动箭头，或用PPT动画展示
  • 请学生上台指出每个环节属于哪一层

五大构成要素（20分钟） ​

  1. 感知层
  2. 网络层
  3. 平台层
  4. 应用层
  5. 安全层（贯穿其他四层）

思政融入：

  • 《网络安全法》第二十一条：网络安全等级保护制度
  • 工业安全的重要性（震网病毒案例回顾）

产业生态与商业模式（15分钟） ​

四类角色：设备商、平台商、集成商、最终用户 三个商业模式案例：

  1. 劳斯莱斯：卖推力不卖发动机
  2. 阿特拉斯科普柯：卖压缩空气不卖空压机
  3. 三一重工：卖设备可用时间，挖掘机指数

回顾反思（10分钟） ​

小组讨论："你未来最想成为四类角色中的哪一类？为什么？"

2.4 动手实践：云服务器注册与远程登录 ​

实践准备 ​

  • 提醒学生提前准备身份证（实名认证需要）
  • 提前收集主流云平台的学生认证信息（阿里云、腾讯云、华为云）

教学流程 ​

环节1：云平台注册与ECS创建（25分钟）

  1. 演示注册阿里云账号（手机注册）
  2. 演示实名认证（可提前完成）
  3. 演示创建ECS实例的关键配置项
    • 地域：离学生最近的
    • 镜像：Ubuntu 22.04
    • 规格：1核1GB
    • 带宽：分配公网IP
  4. 学生练习：注册账号，创建ECS（如果条件限制，可分组完成）

环节2：安全组配置（20分钟）

  1. 讲解安全组是什么（"云防火墙"）
  2. 演示添加入方向规则，开放SSH端口22
  3. 对比讲解：云安全组 vs Windows防火墙 vs 工业防火墙
  4. 工业视角：真实生产环境不应该开放0.0.0.0/0，应限制IP

环节3：SSH登录云服务器（20分钟）

  1. 演示ssh root@公网IP
  2. 演示执行几个命令：timedatectl、curl wttr.in、curl ifconfig.me
  3. 学生练习：登录自己的云服务器，执行几个命令

环节4：本地虚拟机vs云服务器对比（15分钟）

维度本地虚拟机云服务器
位置你电脑里别人机房
关机一起关继续运行
访问局域网全球访问
费用免费按需付费

常见问题与解答 ​

学生问题解答要点
学生认证怎么弄各平台不同，一般需要学信网验证或学生证照片，鼓励课后自行完成
安全组配置后还连不上等待1-2分钟规则生效，检查IP地址是否正确
云服务器太贵怎么办用学生认证免费额度，实验后释放避免扣费
root密码忘了在云控制台重置实例密码

评价设计 ​

  • 成功创建云服务器并远程登录（基础要求）
  • 能说出本地与云端至少3个区别（进阶要求）

本章总结与拓展 ​

核心概念图谱 ​

建议用PPT呈现一张完整的图谱：

  • 底层：传感器、PLC（边缘层）
  • 中层：云平台、大数据、AI（平台层）
  • 上层：MES、预测性维护（应用层）
  • 顶端：ERP、供应链（业务层）
  • 贯穿：安全层

拓展活动建议 ​

  1. 企业调研：参观当地的智能工厂或数字化车间
  2. 案例分析：分组查找一个工业互联网应用案例，用IIRA四层分析
  3. 云服务器探索：在云服务器上尝试安装更多软件（如Node-RED，为第3章做准备）

参考答案（思考与练习） ​

思考题 ​

  1. 你宿舍的无线路由器是工业互联网吗？ 参考答案：不是。逐项对比：连接对象（人vs物）、可靠性要求（偶尔断网没问题vs断网可能出事）、延迟（秒级vs毫秒级）、工作环境（干净舒适vs恶劣）、安全后果（信息泄露vs设备损坏）。

  2. 数控机床实时监控的IIRA四层设计

    • 边缘层：传感器+PLC采集数据
    • 平台层：存储和分析数据
    • 应用层：办公室看板显示状态
    • 业务层：设备利用率统计

  3. 系统集成商项目对接的角色

    • 设备商：提供PLC、传感器
    • 平台商：提供PaaS平台
    • 最终用户：明确需求、付费、使用

  4. 劳斯莱斯模式为什么需要工业互联网

    • 没有实时监控就不知道发动机状态，不敢按小时收费，维修成本会吃掉利润

选择题答案 ​

  1. B（通用电气GE）
  2. C（工业数据量不一定小）
  3. D（边缘层）
  4. B（数据闭环）
  5. B（按飞行小时收费）
  6. C（三一重工）
  7. B（以管理员权限执行）

  1. ×（底层逻辑一致）
  2. √

  4. √

教学反思要点 ​

课后请思考并记录：

  1. 学生对Linux命令的接受度如何？哪些命令掌握最好，哪些最难？
  2. 工业场景的案例是否让学生觉得贴近实际？
  3. 云服务器实践环节有多少学生成功完成？困难主要在哪？
  4. 数据闭环的概念学生是否真正理解了？有什么更好的教学方式？
  5. 思政融入是否自然？有没有更好的切入点？
